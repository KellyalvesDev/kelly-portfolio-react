# Kelly Pitaluga — Portfólio

Portfólio pessoal desenvolvido com **React** e **CSS** (arquivo único global), mantendo o mesmo design visual do projeto original. Migração de HTML/CSS/JS puro para React com componentes funcionais e hooks.

🔗 **[Ver online →](https://KellyalvesDev.github.io)**

---

## 🚀 Como rodar localmente

```bash
# 1. Clone o repositório
git clone https://github.com/KellyalvesDev/kellyalvesdev.github.io.git
cd kellyalvesdev.github.io

# 2. Instale as dependências
npm install

# 3. Inicie o servidor de desenvolvimento
npm start
# Acesse http://localhost:3000
```

---

## 📦 Deploy no GitHub Pages

```bash
# Instala o gh-pages (já está no package.json)
npm install

# Faz o build e publica
npm run deploy
```

> Após o deploy, acesse: **https://KellyalvesDev.github.io**

## 📁 Estrutura do projeto

```
src/
├── assets/               # Imagens e fotos dos projetos
├── components/
│   ├── Navbar.jsx        # Navegação fixa com menu mobile
│   ├── Hero.jsx          # Seção inicial com foto e stats
│   ├── Sobre.jsx         # Apresentação e links sociais
│   ├── Skills.jsx        # Grade de habilidades técnicas
│   ├── Projetos.jsx      # Projetos com filtro por categoria
│   ├── Contato.jsx       # Formulário de contato (mailto)
│   └── Footer.jsx        # Rodapé
├── App.jsx               # Componente raiz
├── App.css               # Estilos globais
└── index.js              # Ponto de entrada
```

## 🛠️ Tecnologias

- **React 18** com componentes funcionais
- **React Hooks** — `useState` (filtro de projetos, menu mobile, formulário) e `useEffect` (scroll do nav)
- **CSS global** (App.css) com variáveis CSS para tema consistente
- **GitHub Pages** para deploy
